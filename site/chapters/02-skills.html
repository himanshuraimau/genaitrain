Chapter 2

What is a skill?

Teach the AI your way of working once. It uses it whenever the task comes up.

The simple version

A skill is a saved "how we do this" guide

Think of the laminated procedure card in a new hire's desk drawer. You don't read it aloud every morning. You pull it out when that situation comes up.

The AI reads a skill only when your request matches it.

Technically it's a folder with one required file, SKILL.md: a name, a note on when to use it, and the steps.

Building a skill for an agent is like putting together an onboarding guide for a new hire.Anthropic engineering blog

Why bother?

Without a skill vs. with a skill

Without

Every week you re-type: "Write the client update. Three sections. Warm tone. Under 250 words. Ask me for notes first..." and it still drifts.

With a skill

You say "client update for Acme" and the AI already knows the format, tone, and what to ask you.

  • Less repeating yourself
  • More consistent output, even across a team
  • Stackable: a writing-style skill plus a brand skill in one task

Under the hood (simply)

How the AI uses a skill

  1. It sees the label. The AI always sees each skill's name and one-line description. Tiny, so you can have many.
  2. It opens the guide. When your request matches a description, it reads the full instructions.
  3. It follows the steps. If the guide points to templates or extra files, it opens those only if needed.

The description is everything. The AI decides from the name and description alone. Say what the skill does and when to use it, using words people really say.

This loading style is called "progressive disclosure" in Anthropic's docs and the open agentskills.io standard.

Peek inside

What a skill looks like

client-update/ SKILL.md ← required references/ ← optional: long guides scripts/ ← optional: exact repeatable steps assets/ ← optional: templates, logos
--- name: client-update description: Writes the weekly client status email. Use when the user asks for a client update, weekly status, or progress email. --- 1. Ask for the client name and this week's notes if missing. 2. Write three sections: Work done, Next steps, What we need from you. 3. Warm, professional tone. Under 250 words.

That's the whole thing. Plain English. No coding.

Good news

One format, many tools

Anthropic created the SKILL.md format and released it as an open standard (agentskills.io). OpenAI, Google and Microsoft now use the same idea.

So a skill you write once is often reusable elsewhere. We map this out in the last chapter.

Safety first. A skill can carry instructions and code. Anthropic's advice: treat skills like installing software. Use ones you trust, read them first, and never put passwords inside.
