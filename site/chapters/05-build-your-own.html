Chapter 5 · Activity

Write your own skill

Three routes, easiest first. Pick the one that fits you.

Three routes

How skills get made

Route 1 · easiest

Ask the AI

Tell it what you want. A built-in skill-creator interviews you and drafts the skill.

Route 2

Record yourself

Do the task on screen while talking. The AI writes the skill from what it saw.

Route 3

Write it by hand

Make a folder, write a SKILL.md, zip it, upload. Works on any plan.

Recording a skill is limited to Pro, Max and Team plans in the Claude desktop app for Mac, and a recording can run about 10 minutes.

Try saying: "Help me create a skill for my weekly status email. Interview me one question at a time about the format, tone and what I always include. Then draft it."

Route 3 (by hand)

Six steps

  1. Make a folder named for the skill: lowercase, hyphens (e.g. weekly-status).
  2. Inside, create a file called SKILL.md.
  3. At the top, add a name and a description (what it does + when to use it).
  4. Write the steps in plain language. Add one example.
  5. Zip the folder. The folder itself must be at the top of the zip.
  6. In Claude: Customize → Skills → upload the zip → switch it on.

Keep the description short. Claude's help page says 200 characters in the upload flow (the developer docs say up to 1,024). Under 200 is safe everywhere.

The method

Build, test, improve

Anthropic's own skill-creator follows a simple loop:

1. Capture

What should it do? When?

2. Interview

Edge cases, examples

3. Draft

Write SKILL.md

4. Test

2 to 3 real prompts

5. Improve

Repeat

  • Explain why a step matters rather than shouting ALWAYS or NEVER.
  • Write descriptions with the words people really say. The AI tends to under-use skills, so be a little "pushy".
  • Test with messy, realistic requests, plus one that should not trigger it.

Did it work?

Test checklist

  • Try 3 prompts that should trigger it. Did they?
  • Try 1 that should not. Did it stay quiet?
  • Does the output match your format every time?
  • No passwords or secrets inside the folder?
  • Didn't trigger? Rewrite the description with more trigger words.
