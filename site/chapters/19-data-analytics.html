Chapter 19 · Build it

From messy files to an answer you can act on

Pull data from more than one place, have the AI clean it, combine it and analyze it, then turn it into a dashboard. No code. Every prompt works in the Claude app and in ChatGPT.

Checked on 5 Nov 2026. Examples are illustrative, not real AI transcripts. Tags: official page readsecondary sourceunverified or untested. OpenAI's help pages blocked our reader, so ChatGPT facts are mostly secondary: check them on your account.

The story we will use

"Signups feel down. Why? What do we do?"

You work at Kite & Co, an imaginary online stationery shop. Your manager asks the question above. The answer is hiding in three systems that don't talk to each other:

Shop system

orders

Who bought what, when, with which discount. Written by humans and plugins, so it is messy.

Website analytics

signups

Visits and new accounts, per day, per channel (Google, Instagram, newsletter…).

Marketing team

ad spend

Rupees spent and clicks, per day, per paid channel.

All the data is made up, by a script, so everyone in the room gets the same files and the same hidden story. The point is the method: connect → clean → combine → ask → show → check.

How it works

The AI doesn't read your numbers. It writes code and runs it.

  1. You ask in plain words: "Which channel grew the most?"
  2. The AI writes a small program (Python is the usual language) to do the counting.
  3. It runs the program in a private sandbox and shows you the table, the chart or a new file.
  4. You check. You can ask to see the code and the steps.
Why that matters

Counting 2,300 rows in a program is reliable. Guessing them "in its head" is not. Insist that numbers come from code, never from memory.

Say this often

"Use code to calculate this. Show me the code or list your steps. Tell me how many rows you used."

Claude: "You can also upload CSV, TSV, and other files for data analysis and visualization." official · ChatGPT runs Python in a notebook-style sandbox; OpenAI advises reviewing the code and its assumptions secondary · Claude Help: Create and edit files

Connecting to data

Three routes in

Route 1

Upload a file

CSV or Excel. A snapshot: true on the day you exported it.

Easiest. Works everywhere.

Route 2

Connect an app

Google Drive, HubSpot, Shopify and more. The AI asks the app for data, using your permissions.

Fresher. Needs setup and approval.

Route 3

Link a live source

A spreadsheet that pulls from a web address and refreshes by itself, or public data you download.

The honest "live" for non-coders.

Pick by how fresh it must be. A report for last quarter? Upload. "Where are we today?" Connector or live sheet.

Route 1 · Upload

File upload: easy, and a snapshot

Claude app official
  • Types: CSV, JSON, TXT, PDF, DOCX and XLSX. To upload XLSX you must have Create and edit files switched on.
  • Chat: up to 500 MB per file and 20 files per chat. Project files: 30 MB each.
  • One Claude help page says 30 MB per file. The two pages disagree, so keep files small and test.
  • Text only is read from most files: pictures inside a spreadsheet are lost.
ChatGPT secondary
  • Takes .csv, .xls and .xlsx.
  • A hard limit of about 512 MB a file is reported, and upload-count caps that differ by plan (free is very low). The numbers vary between versions of the help page.
  • "A file may upload successfully but still be too large ... for complete analysis." Split it if answers look partial.
  • A photo or PDF of a table is unreliable. Upload the real spreadsheet.

Tidy-sheet tips for both: one header row · one row per record · no merged cells · no "Total" row inside the data · one date style. (Our demo file breaks these on purpose, so you can watch the AI fix them.)

The goal of analysis

Observation is not insight

Observation (what)

"Signups fell 20%."

True and useful, but it ends there. Your manager's next words: "Why? So what?"

Insight (what + why + what to do)

"Signups fell 20% because we paused Instagram ads on 6 Oct. Every other channel is flat. Restarting Instagram should win back about 10 signups a day."

The question ladder

  1. What happened? → Where? (split it by channel, country, product)
  2. Why? (what else changed at that time?) → So what? (how big is it?)
  3. Now what? (actions) → How sure are we? (other explanations)

An insight is a claim you could be wrong about. That's why step 6 is "check".

Activity · 6 steps

Do it in this order

  1. Connect: upload the three files (and the dictionary) to Claude or ChatGPT.
  2. Clean: have the AI list the problems, fix them, and report every change.
  3. Combine: join orders, signups and ad spend into one weekly table.
  4. Query: climb the question ladder to an insight.
  5. Dashboard: one page for your manager, then a version that stays live.
  6. Check: verify three numbers by hand and list the assumptions.
Use one app first, then repeat one step in the other. Compare: what did each do differently?

Start a new chat for each app. Attach all four files (three data files and the dictionary) in one message.

Step 1 · Connect

Upload, then "look, don't touch"

  1. Claude: open a new chat. Check Settings → Capabilities → Create and edit files is on. ChatGPT: open a new chat.
  2. Drag in orders.csv, signups.csv, ad_spend.csv and data-dictionary.txt.
  3. Paste this and send.
I have attached three files from an online shop called Kite and Co (orders.csv, signups.csv, ad_spend.csv) and a data dictionary.
Do not change or fix anything yet. Use code to count, don't estimate.
For each file tell me:
1. How many rows and columns, and the date range.
2. What each column means, in one line.
3. Anything that looks wrong, inconsistent or suspicious, with a count and 2 example rows.
Then list 5 business questions this data could answer.
  • Did it find the mixed date styles and the many spellings?
  • Do the row counts match the table on page 9 (2,303 / 450 / 180)?
  • Did it say whether it read all the rows?

Step 2 · Clean

Fix it, and show every change

Clean orders.csv with exactly these rules, and nothing else:
- One date format, YYYY-MM-DD. Dates written like 06/10/2026 are day first.
- country: one spelling per country (India, UAE, Singapore, United States).
- channel: one of google, instagram, newsletter, referral, direct.
- status: Title Case (Delivered, Shipped, Cancelled, Refunded).
- Remove rows that are exact copies of another row.
- Remove test orders (customer_id TEST).
- Do NOT delete rows with a negative quantity or a unit price above 5,000. Put them in a separate list called "needs a human".
- Blank category: fill from the product name only when it is obvious.
Then give me:
1. A table of every change: rule, rows changed.
2. Row count before and after, and how the difference adds up.
3. The cleaned file as a CSV I can download.
Keep my original data untouched.
  • Do the numbers add up? (rows before − removed = rows after)
  • Open the "needs a human" list. Do you agree with each one?
  • Did it change anything you didn't ask for? Ask: "List any assumption you made."

Typical result: about 38 repeated orders, 3 test orders, 7 negative quantities and 3 very high prices (illustrative: check your own counts).

Step 3 · Combine

Join three tables into one weekly table

Using the cleaned orders plus signups.csv and ad_spend.csv, build ONE weekly table (weeks start on Monday) with these columns:
week_start, channel, visits, signups, ad_spend_inr, orders, revenue_inr.
Rules: revenue is quantity times unit price, minus the discount (SAVE20 = 20 percent off, WELCOME10 = 10 percent off). Leave out cancelled and refunded orders. Where a channel has no ad spend, use 0.
Then tell me:
1. Which columns you joined on, and why that is safe.
2. Row counts of each input and of the result.
3. Check: do total signups, total ad spend and total orders in the weekly table match the source files? Show both numbers.
Give me the table as a CSV I can download.
Why the checks matter

A wrong join can double-count rows without any error. Totals that match the sources are your safety net.

If the totals differ

Ask: "Why are the totals different? Show the rows that explain it." Don't continue until they match.

Step 4 · Query

Climb the question ladder

Ask these one at a time, reading each answer before the next. Keep it in the same chat.

1. WHAT: How did total weekly signups change over the whole period? Compare the last 4 weeks with the 4 weeks before. Give the percentage.
2. WHERE: Split that change by channel. Which channels moved, and by how much?
3. WHY: What else changed around the time it started? Compare with ad spend and orders by channel and by week. Show the numbers that support your answer.
4. SO WHAT: How many signups and how much revenue did we lose in the last 4 weeks because of this? Say how you estimated it.
5. NOW WHAT: Give 3 actions, each with the first thing to check and what could go wrong.
6. HOW SURE: What other explanations could there be? What data would prove or disprove each one?
Finally, write the insight in 3 sentences my manager could read in 20 seconds.

A good answer has: a number, a reason backed by data, an action, and a doubt. If one is missing, ask for it.

Observations are easy to get. The "why" and "now what" need you to question them. Ask the AI: "What would make you wrong?"

Step 5 · Build it

A one-page dashboard for your manager

Using the weekly table we built, make a one-page dashboard for my manager.
Include:
1. Four big numbers: signups in the last 4 weeks (and % change vs the 4 before), orders, revenue, ad spend.
2. A line chart of weekly signups, one line per channel.
3. A bar chart comparing Instagram and Google: ad spend next to signups.
4. A box titled "What to do next" with the 3 actions we agreed.
5. A small line saying "Data as of [last date in the data]".
Plain colours, big labels, nothing that needs explaining. Don't invent numbers: use only the table.
In the Claude app

It builds an artifact, a page you can click, hover and open full-screen. Ask for changes in the chat ("make the Instagram line red"). To share: share the artifact (a link works on every plan) official. This is a snapshot. It does not refresh itself.

In ChatGPT

It makes charts and a summary in the chat. Add: "Make the charts interactive, and give me the 4 numbers as a small table." Download the charts or ask for an Excel file to paste into slides.

  • Do the four numbers match your table from step 3?
  • Is there a "data as of" date?
  • Would your manager understand it in 20 seconds?

Step 5 · Make it stay live

A Google Sheet that refreshes by itself

  1. New Google Sheet. In tab 1 cell A1 paste the signups formula. Make tab 2 and paste the ad spend one in A1. (They are the clean tables, so they need no cleaning.)
  2. Install the AI add-on for your sheet (see the box), open it from the Extensions menu, and paste the prompt below.
  3. Come back tomorrow. The data tabs now include a new day. The summary updates because it uses formulas.
Tab 1, cell A1
=IMPORTDATA("https://genai-notebook.vercel.app/api/shop?table=signups")
Tab 2, cell A1
=IMPORTDATA("https://genai-notebook.vercel.app/api/shop?table=ad_spend")
In this workbook, tab 1 holds website signups and tab 2 holds ad spend; both refresh from the web.
Add a "Summary" tab, using formulas only (no typed numbers):
- Weekly signups by channel (weeks start Monday), for the last 12 weeks.
- Weekly ad spend for Google and Instagram.
- A cell showing the % change in total signups, last 4 weeks vs the 4 before.
- A line chart of weekly signups by channel.
Explain each formula in one line. Don't change tabs 1 and 2.
Claude in Google Sheets official, beta

Pro, Max, Ultra, Team, Enterprise. Install from the Google Workspace Marketplace, then Extensions → Claude → Open Claude. Keep the sidebar open while it works. One long step can run up to six minutes.

ChatGPT for Google Sheets secondary

Reported as out of beta since May 2026, on every plan (free is limited). Install from the Marketplace, then Extensions. Check your plan.

IMPORTDATA refreshes about hourly, not instantly. The AI add-ons read the sheet you have open, so formulas and live values stay. (The Drive connector, by contrast, gives Claude a CSV copy: formulas are lost.)

Step 6 · Check

Don't trust. Verify three numbers.

Help me check your work.
1. Pick the 3 most important numbers in your conclusion. For each, tell me exactly how I can reproduce it by hand in the original file: which file, which filter, which column, which sum.
2. List every assumption you made (date style, discounts, what you removed, how you joined).
3. Tell me the single biggest way your conclusion could be wrong.
4. How many rows did you actually use from each file?

Then do it yourself (10 minutes)

  1. Open the original signups.csv in Excel or Sheets.
  2. Filter for Instagram, add up the last 4 weeks. Does it match?
  3. Do the same for ad spend. Does the pause date match?

If it doesn't match, that is not a failure. It is the lesson. Ask the AI: "My number is different. Show me exactly how you got yours."

Pasted numbers
