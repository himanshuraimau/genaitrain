Your first skill in 10 minutes

Copy a ready-made skill, install it, and watch it work. Two skills, step by step.

The plan

What we'll do

  1. Copy the skill text with one click.
  2. Install it (two ways: paste into chat, or upload a file).
  3. Test it with one prompt that should trigger it, and one that shouldn't.
  4. Change one line to make it yours.

Both skills below are written for this course. The "interview first" idea is inspired by Matt Pocock's grill-me and Jesse Vincent's brainstorming (Chapter 9); the rewrite idea by pstack's unslop.

Skill 1 of 2

plan-grill

It interviews you about a plan, one question at a time, before anything gets written. Good for events, projects, launches, study plans.

---
name: plan-grill
description: Interviews you one question at a time to sharpen a plan before any work starts. Use when asked to grill me, poke holes, or stress-test a plan.
---
# Plan grill

Goal: reach a shared understanding of the plan before writing or doing anything.

1. Restate the plan in two sentences and ask if that is right.
2. Ask ONE question at a time. Wait for the answer before asking the next.
3. With every question, give your own recommended answer and a one-line reason, so I can reply "yes" or correct it.
4. Go in this order: goal, audience, constraints (time, money, people), risks, and what "done" looks like. If one answer changes another, settle that one first.
5. If the answer is in files or notes I shared, look it up instead of asking me.
6. When no open questions remain, write a one-page summary: goal, decisions made, open risks, next three steps.
7. Do not start the actual work until I say the summary is right.

Description is 140 characters, safely under the 200 limit.

Install, route A (any tool, no files)

Paste it into a chat

  1. Click Copy on the previous page.
  2. Open a new chat in ChatGPT, Claude or Gemini.
  3. Type: "Create a skill from the text below and save it." Then paste.
  4. Approve when it asks to save. It will use its built-in skill-creator.

If it says it can't save skills: your plan may not include skills yet (ChatGPT's help page lists Business, Enterprise, Healthcare and Edu). Use route B for Claude, or the fallback on the last page.

Install, route B (Claude, upload a file)

Make the file yourself

  1. On your desktop, create a folder named plan-grill.
  2. Open a plain-text editor (Notepad, or TextEdit with Format → Make Plain Text). Paste the text.
  3. Save inside the folder as SKILL.md. Check the name: not SKILL.md.txt.
  4. Compress the folder to a zip (right-click → Compress / Send to → Compressed folder). The folder must be at the top level of the zip.
  5. In Claude: Customize → Skills → add / upload the zip, then switch it on. Code execution must be enabled in settings.

Source: Claude Help: Creating custom skills

Test it

Two prompts

Should trigger

"I'm planning a 2-day team offsite for 20 people next month. Grill me on the plan."

Expect: one question at a time, each with a suggested answer.

Should stay quiet

"What's the capital of Australia?"

Expect: just an answer, no interview.

  • Did it ask only one question at a time?
  • Did each question come with a recommended answer?
  • Did it end with a one-page summary and wait for your OK?

Didn't trigger? Add the words you actually use to the description, like "stress-test" or "review my plan".

Skill 2 of 2

plain-english-edit

Makes a draft sound like a person wrote it. Good for emails, reports and posts.

---
name: plain-english-edit
description: Rewrites text in plain, human-sounding English: short, concrete, no filler. Use when asked to simplify, tighten, remove jargon, or make text sound less like AI.
---
# Plain English edit

Rewrite the text I give you. Keep my meaning and facts. Change only the wording.

1. Use short sentences and everyday words. Prefer "use" over "utilize".
2. Cut filler openers ("In today's fast-paced world", "It is important to note") and empty closers.
3. Replace vague claims with the specific detail I gave. If a detail is missing, keep the claim plain instead of inventing one.
4. Remove stacked adjectives, hype words, and repeated points.
5. Keep my voice: if I wrote casually, stay casual.
6. Return the rewrite first, then a short list of what you changed and why (max 5 bullets).
7. Never add facts, numbers or quotes that were not in my text.

Install it the same way as skill 1. Test: paste a stiff paragraph and say "make this plain English".

Make it yours

Change one thing

plan-grill

Edit step 4. Swap the order for your world, e.g. "learning goal, time per week, resources, how I'll check progress" for a study plan.

plain-english-edit

Edit step 5 to name your tone: "formal and warm, like a banker writing to a long-time client."

Then re-test with the two prompts. This loop (edit, test, edit) is how the skill builders in Chapter 9 work too.

A skill is never done. Marcus Moretti edited his about 50 times (Chapter 6).

For the teacher

How to run this in class (20 min)

  1. 2 min: Show the page. Ask: "What do you re-explain to an AI every week?"
  2. 3 min: Demo skill 1 yourself on screen. Click Copy, install by route A.
  3. 5 min: Everyone installs it (route A for most, route B for Claude users who want to see the files).
  4. 5 min: Everyone runs the two test prompts on their own plan.
  5. 5 min: Everyone edits one line, re-tests, and shares what changed.

Tip: do route A first for the room. Show route B on your own screen so they see that a skill is just a folder with a text file.

If something goes wrong

Troubleshooting

ProblemFix
No Skills menuYour plan or admin settings may not include it. Use the fallback below.
Upload failsCheck the folder is at the top level of the zip, and the file is exactly SKILL.md.
Skill doesn't triggerName it in your prompt ("use plan-grill"), then rewrite the description with your own trigger words.
Triggers too oftenMake the description narrower; add "only when the user asks to..."

Fallback that works everywhere: paste the skill text at the start of a chat and say "follow this for the rest of the conversation". Or put it in a Project's instructions. It's not a true skill, but the behavior is the same.
