Where to find good skills

Official libraries, GitHub collections, and how to tell a good one from a risky one.

Start here (safest)

Official sources

SourceWhat you get
anthropics/skillsAnthropic's example library: document skills, brand-guidelines, doc-coauthoring, internal-comms, theme-factory, skill-creator and more. Roughly 185k GitHub stars. For learning: test before relying on them.
agentskills.ioThe open standard, specification, quickstart and a list of tools that support it.
ChatGPT Plugin DirectorySkills tab, with skills bundled into plugins. Plan availability varies.
Partner skillsNotion, Figma and Atlassian ship skills for their own apps.

OpenAI's older openai/skills repo is marked deprecated and points to a newer plugins repo.

Community collections

GitHub "awesome lists"

awesome-claude-skills

Curated list: documents, marketing, writing, productivity, plus automation for ~78 apps. About 78k stars.

awesome-copilot

GitHub's community collection of skills, agents and plugins. Browsable website. About 40k stars.

Awesome-Agent-Skills

Categorized, with an installer for several tools. Small but tidy.

skills.sh

A directory and leaderboard of skills (launched by Vercel, Jan 2026) with a one-line installer.

For non-technical learners: look in the sections called Document Processing, Business & Marketing, Communication & Writing, Productivity. Most of GitHub is built for developers, and that's fine to skip.

Star counts are snapshots and change daily.

Before you install anything

The 5-point safety check

  1. Who made it? Official or well-known beats anonymous.
  2. Open the folder. Is SKILL.md readable? Are there scripts?
  3. Look for red flags: links to unknown sites, requests for passwords or keys, behavior that doesn't match the description.
  4. Check the license. Some document skills are source-available, not open source.
  5. Test on dummy data first. Never first-run on confidential files.
Treat skills like installing software.Paraphrasing Anthropic's security guidance. ChatGPT also scans uploaded skills and marks them Ready, Needs Review or Blocked.

Easiest path

No GitHub needed

Just ask your AI:
"I do a weekly status report. Help me turn it into a skill."
Start with the built-in document skills, then make your own (Chapter 5). A skill you wrote yourself is the one you trust most.
